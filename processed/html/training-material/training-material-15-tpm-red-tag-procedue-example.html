SCOPE :

TPM Tag Process :

1) Number and attached tag to item in need of repair

2) Post Red tag on board

3) When item is repaired rip off yellow tag and post on board with date

4) Four week later verify that repair was root cause

5). Remove green tag and post on board for one month

STANDARD/SPECIFICATION

The Following Standards are to be adopted when a TPM tag is put up in the Manufacturing during the daily observation taken by operator on the shop floor in NHB Group. Standards are defined

1) Red Tag

2) Yellow Tag

3) Green Tag

1. Tag Process Card's

> Red Tag, Yellow Tag, Green Tag

Filled by Operator/ Machine Owner

Abnormality in Verification Period

Filled By Observer ( Operator/ Machine Owner )

Abnormality is Identified

Abnormality is Solved

Filled by Repair Guy

> Red Tag : Red tag is filled by Operator/ Machine owner.

Red tag is used when an operator/Machine owner found abnormality.

> Yellow Tag : Yellow tag is filled by Repair Guy ( Fitter, Electrician, Welder, Fabricator )

Yellow tag shows that a repair guy ( Fitter, Electrician, Welder, Fabricator ) tracking abnormality and solve it.

> Green Tag : Green tag is filled by an Operator/ Machine owner after 4-Weeks of Repair made. ( Machine is in observation period )

Green Tag is used after repair guy is solved abnormality, and 4-week after that no abnormality or problem is repeated.

Step -1 : When and Operator/ Machine owner found any abnormality they've to fill TPM Red Tag. In which they've to fill Observer Name, M/c Number, Date, and reason for red tag.

Step-2 : From TPM Tag red tag will move to the channel TPM Board

Step-3 : Repairer Guy check daily TPM Board and as per Red tag, he will tracking that abnormality and solve it.

Step-4 : After solve that abnormality, Repairer guy fill 4-week sustain date in Green Tag.

Step-5 : Yellow tag will move to Channel TPM Board. And green tag card remain at machine.

Step-6 : After 4-week of observation if abnormality not repeated then Green Tag move to the Channel TPM Board

Setp-7 : Green Tag will be stayed on the board for the 1-month. And after 1-Month it'll move from Channel TPM Board.

Step 8 : The summary data will be entered into the TPM record file to allow for easy searching and analysis

Step 9 : Monthly, a team will pareto the red tags to determine if the PM plan needs to be modified to preventively solve the issue
